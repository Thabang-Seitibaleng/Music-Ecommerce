# SEN 371: Software Engineering - Group 6
In this project, we demonstrate how we built a full-stack e-commerce web application.

The project is developed using a **React and TypeScript frontend**, a **Node.js and Express backend**, and a **MySQL database**, with RESTful APIs connecting the different layers of the application.

# 🎯 Project Overview

The system consists of three main components:

- **Frontend** – User interface and client-side functionality
- **Backend** – RESTful API and application logic
- **Database** – Persistent storage for users, products, and orders

The system is developed collaboratively using Git and GitHub, with the frontend and backend deployed separately to provide a working, accessible system.


## 🛠️ Technologies Used

- **Frontend:** React, TypeScript, Vite
- **Backend:** Node.js, Express, TypeScript
- **Database:** MySQL
- **Deployment:** GitHub Pages
- **Version Control:** Git & GitHub


## ✨ Features

- User registration and login
- Product browsing
- Product details
- Shopping cart
- Checkout
